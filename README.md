# Jai Jalaram Tours & Travellers 🚩
### All Gujarat 24/7 Travel Service • Doorstep Pickup Anywhere in Gujarat

A modern, ultra-responsive web platform for **Jai Jalaram Tours & Travellers**, providing group booking, four-wheeler family cars, luxury Tempo Travellers, and deluxe tourist coach buses across the state of Gujarat.

---

## 🌟 Key Features

- **Dynamic Fleet & Family Accommodations**:
  - **4-Wheeler Sedans (2–4 Pax)**: Swift Dzire, Toyota Etios (economical, chilled AC).
  - **Family MUVs (5–7 Pax)**: Toyota Rumion, Maruti Ertiga, XL6 (roof AC, flexible luggage boot).
  - **Executive VIP Cars (6–8 Pax)**: Toyota Innova Crysta, Innova Hycross (captain recliner seats).
  - **Medium Groups (10–20 Pax)**: Force Luxury Maharaja Tempo Travellers (14/17/20S).
  - **Large Groups & Pilgrimages (25–56 Pax)**: Commander AC Luxury Coach Tourist Buses (air-suspension, night ambient LED).

- **Authentic Fleet Gallery**:
  - Real operational photos featuring the **Commander AC Luxury Tourist Bus** (Day Highway & Overnight Ambient Lighting Views) and the **Toyota Rumion Family MPV**.
  - Interactive Family Member Accommodation Guide with one-click vehicle booking.

- **Dynamic Google Translation Engine**:
  - On-the-fly translation into **English** (default), **ગુજરાતી (Gujarati)**, and **हिंदी (Hindi)**.
  - Dedicated language-to-language transition loader (`English` ➔ `ગુજરાતી`) with visual status progress.

- **Multi-Page Simulation Loader**:
  - Smooth section transition loader featuring the central brand logo with glowing concentric spinner rings for seamless navigation.

- **Instant Booking Modal & Direct Contact**:
  - Dynamic vehicle pre-selection.
  - One-tap Direct Call to Kushangbhai (`+91 99258 91467`).

## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (Tailored Ultra-White Corporate Theme)
- **Icons**: Lucide React
- **Translation**: Google Translate Dynamic Element API

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
